## Topics covered

- Network topologies: star, bus, mesh and hybrid
- Router configuration using GUI and CLI
- DHCP and IP address assignment
- FTP, HTTP and DNS services
- IPv4 addressing, subnet masks and connectivity verification

## How to use

1. Open the relevant experiment folder.
2. Read its README and refer to the official assignment brief.
3. Download the corresponding `.pkt` project once it is present in the repository.
4. Open the project in Cisco Packet Tracer and perform the verification steps.

# Cisco Packet Tracer Experiments

A practical collection of Computer Networks laboratory work implemented using Cisco Packet Tracer.

## Repository contents

Each experiment is organized in its own folder and, where available, includes:
- The original assignment brief (PDF)
- The Packet Tracer project file (`.pkt`)
- A step-by-step experiment README
- Screenshots showing topology and verification

## Experiments

| No. | Experiment | Included files | Status |
|---|---|---|---|
| 07 | Router configuration using GUI and CLI | Assignment brief and documentation | Documentation added; `.pkt` file pending |
| 09 | FTP, HTTP and DNS server configuration | Assignment instructions visible in working screenshot | Source files pending upload |

## Tools and concepts

- Cisco Packet Tracer
- IPv4 addressing and subnet masks
- Routers, switches and end devices
- GUI and CLI configuration
- FTP, HTTP and DNS services
- Connectivity testing with ping and Simple PDU

## How to use

1. Open the experiment folder.
2. Read its `README.md` and the assignment brief.
3. Download the `.pkt` file when available.
4. Open it in Cisco Packet Tracer and follow the documented verification steps.

# Assignment 06: Network Topologies

## Aim

Create and compare network topologies using Cisco Packet Tracer.

## Supplied project variants

| Topology | Packet Tracer source filename |
|---|---|
| Star | `Assingnment_6-STAR.pkt` |
| Bus | `Assingnment_6_BUS.pkt` |
| Mesh | `Assingnment_6_MESH.pkt` |
| Hybrid | `ASSIGNMENT_6_HYBRID.pkt` |

## What to examine

For each topology, inspect the device arrangement and links in Packet Tracer. Compare the physical/logical layout and verify communication between the connected end devices according to your lab instructions.

## Verification

Use Simulation Mode / Simple PDU or the connectivity test specified by your assignment to confirm that the topology behaves as expected.
